# 설계 문서 (Phase 0)

주문 · 결제 · 정산 이벤트 드리븐 MSA 포트폴리오 프로젝트의 설계 문서 모음.

## 읽는 순서

1. **[event-design-v0.1.md](./event-design-v0.1.md)** — 범위, 이벤트 스토밍 결과, 이벤트 카탈로그, 토픽 설계, 페이로드 스키마
2. **[erd-v0.1.md](./erd-v0.1.md)** — 서비스별 ERD(Mermaid), 주문 상태 머신, 스키마 설계 노트
3. **[adr/](./adr/)** — 아키텍처 의사결정 기록
4. **[glossary.md](./glossary.md)** — 용어집 (초급자용, 프로젝트 맥락 연결)

## ADR 목록

| 번호 | 제목 | 상태 |
|---|---|---|
| [0001](./adr/0001-incremental-event-driven-migration.md) | 동기 호출로 시작해 이벤트 드리븐으로 단계 전환한다 | 승인됨 |
| [0002](./adr/0002-multimodule-monorepo.md) | 멀티모듈 모노레포로 관리한다 | 승인됨 |
| [0003](./adr/0003-two-phase-cancellation.md) | 고객 취소는 2단계(요청 → 환불 확인 → 확정)로 처리한다 | 승인됨 |

> 미결 ADR 후보(#5~#11)는 각 설계 문서 하단 표 참고. 해당 Phase 도달 시 결정하고 한 장씩 추가한다.

## 문서 운영 규칙

- 설계 문서는 버전을 올리며 갱신한다 (v0.1 → v0.2). "최종"은 없다.
- ADR은 수정하지 않는다 — 폐기/대체로 상태만 바꾸고 새 번호로 작성한다. ([템플릿](./adr/template.md))
